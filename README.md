# 行動予定ボード

事務所のホワイトボード（行動予定表）を置き換える Web アプリです。
人の配置・車両の使用予定・現場・トラブル・連絡事項・来客予定を1画面に表示し、スマホや PC からも閲覧・編集できます。

- サーバーを持たない静的サイトです（GitHub Pages で配信）。
- データは **別の非公開リポジトリ** の JSON ファイルに保存します。このリポジトリにはプログラムしかありません。
- 各端末には「登録コード」を1回だけ入力します。登録していない端末からは何も見えません。

## 画面

| 画面 | 内容 |
|---|---|
| ボード（`#/board`） | 大画面用の常時表示。名札・車両の帯をドラッグで動かせます |
| 予定入力（`#/input`） | グループ別の人員 × 日付の表。マスをなぞって予定を入力します |
| 管理（`#/admin`） | 人員・グループ・車両の管理、端末の登録コード、バックアップ |
| スマホ表示 | 画面幅が狭いと自動で切り替わります |

## お試しモード

登録画面の「お試しモードで開く」を押すと、架空のデータで操作を試せます。データはそのブラウザの中だけに保存されます。

## データの置き場所と登録コード

- データ用リポジトリ（非公開）に `data/master.json` `data/schedules.json` `data/notes.json` を保存します。
- 鍵は、データ用リポジトリ1つだけに「Contents: Read and write」を許可した fine-grained personal access token です。
- 登録コードは「アカウント名・リポジトリ名・ブランチ名・鍵」を1つの文字列にまとめたものです（登録画面の「登録コードを作る」で作成）。
- 登録コードは端末のブラウザ内（localStorage）にのみ保存されます。業務データは端末に保存しません。
- 実行時の通信先は `https://api.github.com` のみです（Content-Security-Policy で制限）。

## 開発

```
npm ci --ignore-scripts
npm run dev      # 開発サーバー
npm test         # テスト
npm run build    # dist/ に出力
```

`main` に push すると、GitHub Actions がテスト・ビルドのうえ GitHub Pages に配信します
（リポジトリの Settings → Pages → Source を「GitHub Actions」にしてください）。

## 構成

```
src/domain/   日付・表示の導出・操作（純粋関数）
src/data/     保存先（お試し用 / GitHub 用）と同期
src/ui/       画面
```
